# [현대차 공시 자동 갱신]

## [자동으로 기록하는 항목]

GitHub Actions는 평일 한국시간 오전 8시 20분에 DART를 조회한다. 사업보고서, 반기보고서, 분기보고서, 영업잠정실적 공시 가운데 새로 접수된 항목을 찾는다.

새 공시가 있으면 `data/disclosure_watch.json`과 `report/DISCLOSURE_UPDATE_LOG.md`에 접수번호와 DART 원문 링크를 기록한다.

## [자동으로 바꾸지 않는 항목]

공시 감지는 실제치, 전망, 투자의견, 목표주가를 자동으로 수정하지 않는다. 현대차는 제조업과 금융사업이 함께 연결되므로 다음 항목을 원문과 회사 IR 자료로 대조한 뒤 반영해야 한다.

- 도매판매와 지역별 판매
- HEV·EV 비중과 인센티브
- 자동차 부문 영업이익률
- 금융채권, 조달부채, 신용손실
- 자동차 CAPEX와 연구개발 투자
- 배당, 자사주, 경제적 주식 수
- 지배주주 자본과 비지배지분

## [GitHub Secret 설정]

저장소 Settings → Secrets and variables → Actions에서 `DART_API_KEY`를 추가한다. OpenDART에서 발급받은 인증키를 값으로 저장하면 다음 예약 실행부터 자동 조회가 시작된다.
